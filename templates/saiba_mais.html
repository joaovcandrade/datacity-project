Sobre o DataCity

O DataCity é uma plataforma desenvolvida por estudantes de Ciência da Computação da Unifil, em parceria com o Núcleo de Práticas em Informática (NPI) da instituição, com o objetivo de revolucionar a gestão e análise de dados urbanos.

Nossa missão: Fornecer uma solução centralizada e inteligente para que gestores públicos, pesquisadores e cidadãos possam acessar, analisar e compreender os dados que moldam nossas cidades.

A plataforma foi concebida para atender às crescentes demandas por transparência, eficiência e tomada de decisão baseada em dados no contexto urbano. Com uma interface intuitiva e ferramentas avançadas de análise, o DataCity democratiza o acesso à informação urbana.

Principais Funcionalidades

Análise Multidimensional

Explore dados urbanos nas principais dimensões, estendendo desde mobilidade até governança.

Indicadores Inteligentes

Acompanhe indicadores-chave baseados em normas ISO e ODS da ONU.

Coleta Automatizada

Sistema avançado de web scraping para coleta automática de dados públicos.

Relatórios Dinâmicos

Geração automática de relatórios personalizados e visualizações interativas.

Gestão de Normas

Integração com normas ISO 37120, 37122, 37123 e 37125 voltadas a cidades inteligentes.

Segurança Avançada

Sistema de autenticação robusto com diferentes níveis de acesso.

Arquitetura do Sistema

A plataforma foi desenvolvida seguindo as melhores práticas de engenharia de software, utilizando o framework Django para garantir escalabilidade, segurança e manutenibilidade. A arquitetura modular permite fácil extensão e integração com outras plataformas.

Diferenciais do projeto: Integra conceitos de desenvolvimento web, análise de dados e engenharia de software.

Nossa Visão

Transformar o DataCity em muito mais do que uma simples plataforma: queremos criar um ecossistema completo de soluções voltadas para o desenvolvimento de cidades inteligentes. Buscamos ser a principal referência em plataformas de dados urbanos no Brasil, promovendo cidades mais inteligentes, sustentáveis e eficientes, que utilizem a tecnologia como ferramenta para melhorar a qualidade de vida das pessoas.
